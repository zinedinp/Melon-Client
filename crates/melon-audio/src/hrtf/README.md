# default.mhr

OpenAL Soft's built-in HRTF data set ("Default HRTF", format `MinPHR03`, 48 kHz,
64 taps, 828 directions), the one vanilla hears through LWJGL's OpenAL Soft when
"Directional Audio" is on. Copied unchanged from OpenAL Soft 1.25.2
(`share/openal/hrtf/Default HRTF.mhr`, sha256
`0b2f09f4d9167dec4e977e7e1a8c78df17e87da06fb0871b9896fadaa473a440`).

OpenAL Soft is LGPL-2.1-or-later. The data set is based on the KEMAR HRTF
measurements by Bill Gardner and Keith Martin, MIT Media Lab
(<http://sound.media.mit.edu/resources/KEMAR.html>), which may be used freely
as long as that source is credited.
